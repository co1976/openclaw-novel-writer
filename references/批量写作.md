# 批量写作模式

## 触发
用户说「批量写章」或「写第X-Y章」时进入。

## 流程

1. **章纲批量加载**：读取X-Y章的防偏章纲或写作蓝图
2. **情绪曲线统筹**：确保X-Y章整体情绪有起伏，避免连续低落
3. **爽点分布优化**：不能连续2章无爽点
4. **钩子链设计**：X章钩子 → X+1章承接 → X+2章推进
5. **批量产出**：按顺序写作，每章保持风格一致
6. **批量检查**：统一检查字数/情绪/合规
7. **Codex批量更新**：逐章更新状态

## 输出格式

```
【第X-Y章批量写作完成】

第X章：[标题] - [字数]字 - 情绪曲线：[曲线] - 人味评分：[分数]
第X+1章：[标题] - [字数]字 - 情绪曲线：[曲线] - 人味评分：[分数]
...
第Y章：[标题] - [字数]字 - 情绪曲线：[曲线] - 人味评分：[分数]

总计：[总字数]字，平均每章[平均字数]字
情绪稳定性：[波动程度]
AI痕迹平均分：[平均分]
```

## 质量均衡要求

- 章节间字数差 ≤500字
- 相邻章节情绪起点差 ≤2分
- 不能连续2章无爽点
- 整体情绪曲线有起伏但不剧烈
- 钩子链不能断裂（X章钩子必须X+1章接）

## 段落分配模板（2500字标准）

```
段落1: 0-300字    场景建立+承接上章
段落2: 300-800字   问题出现+主角反应
段落3: 800-1500字  主角行动+小障碍
段落4: 1500-2000字 爽点释放+对手反应
段落5: 2000-2300字 成果影响+情感互动
段落6: 2300-2500字 章末钩子+下章预告
```

## 速度目标

- 单章写作：45-60分钟（2500字）
- 日更万字：3-4小时（4章）
- 批量效率：8章/6小时（含检查）
