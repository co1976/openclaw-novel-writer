# 情绪曲线管理

## 情绪评分标准（1-10分）

| 分数 | 状态 | 适用场景 |
|------|------|---------|
| 1-3 | 平淡/低落 | 过渡章、悲剧段落 |
| 4-6 | 正常推进 | 日常章、案件调查 |
| 7-8 | 小高潮 | 破案、温情高峰、冲突爆发 |
| 9-10 | 大高潮 | 真相揭露、最终对决、重大转折 |

## 预设曲线

按章节类型预设情绪目标：

```
案件章：3→4→5→7→6      （引入线索→调查→受阻→突破→钩子）
日常章：4→5→6→5       （生活场景→互动升温→冲突→缓和收尾）
悬念章：5→4→3→6→7     （异常→困惑→压力→发现→更大悬念）
情感章：4→6→8→6→7     （日常→互动→冲突→让步→升华）
高潮章：6→7→5→9→8     （准备→危机→绝望→反转→余波）
```

## 偏差处理

| 偏差 | 处理 |
|------|------|
| ≤1分 | 正常，记录即可 |
| 1-2分 | 调整下章情绪 |
| >2分 | 立即分析原因，调整后续3章 |

## 情绪实时校准（写中）

每500字检查当前情绪分数：
- 偏离计划 → 调整对话/描写/动作
- 确保情绪曲线按计划走

## 每章情绪记录格式

```
第[X]章：[标题]
预设曲线：[3→4→5→7→6]
实际曲线：[3→4→6→7→6]
偏差：[+1处在第3节]
说明：[调查受阻的情绪被适当放大]
```
