# 卡文破局方案

卡文时不直接硬写，先生成三种破局方案，选最能增强追读的一种。

## 方案一：压力升级法

让外部压力迫使主角立刻行动，不能停下来思考。

```
给主角加时间限制——"三炷香内不找到答案，XX就死。"
让环境恶化——"火势蔓延，出口被堵。"
让对手逼近——"追兵已经到门口了。"
```

**何时用：** 剧情停滞、主角不知道下一步该怎么办、气氛沉闷

## 方案二：信息反转法

给出一个新事实，推翻主角原判断，引发新的行动。

```
"她根本不是你说的那个人。"
"死者不是自杀，你看这个痕迹。"
"那封信是他伪造的。"
```

**何时用：** 主角陷入错误方向、读者都知道但主角不知道、太顺利

## 方案三：关系撬动法

让关键角色之间的关系发生冲突、误会、背叛或保护，推动剧情。

```
配角突然反水——"我一直等着这一天。"
CP关系紧张——"你不信我？"
旧敌变救星——"欠你的人情，今天还了。"
```

**何时用：** 主线推进太满需要调剂、读者对纯事件推进疲劳、需要深化人物

## 选择原则

1. 选择最符合当前章节情绪走向的方案
2. 选择最能产生「下一章一定想看」效果的方案
3. 不为了破局而引入新角色（避免角色膨胀）

## 通用应急方案

如果以上三种都不想用：

- **Skip**：跳过这段，从有感觉的场景开始写
- **跳切**：直接跳到下一段对话或动作场景
- **废稿生成**：先乱写一版，再删改——写废了比空着好
