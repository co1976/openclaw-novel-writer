# 番茄小说平台合规细则

## 字数规定
- 单章字数：2000-3000字（最优）
- 最低：1500字（紧急情况）
- 最高：4000字（高潮章例外）
- 8万字可发起推荐评估
- 10万字进正式推荐
- 申请推荐前需连续3天日更4000字+

## 分段规定
- 每段行数：2-5行
- 对话单独分段
- 场景转换空行
- 手机阅读适配（每段不宜过长）

## 章节结构
- 章节名：8-15字，有吸引力
- 开篇：前100字必须有钩子
- 中段：每500字一个小起伏
- 结尾：最后100字必须有悬念钩子
- 破折号：全章不超过2处（平台合规）

## 章末模板
```
【求数据】
求推荐票！求月票！求收藏！
打赏加更规则：盟主+2章！
```

## 推荐申请条件
- 8万字可发起推荐评估
- 10万字进正式推荐
- 核心指标：章节追读率、章节读完率
- 申请推荐前需连续3天日更4000字+
- 中高质量小说每章2500字以上

## 平台算法偏好
- 开篇3秒抓住读者（前100字）
- 每章一个强钩子
- 追读率 > 字数
- 稳定更新 > 爆发更新
