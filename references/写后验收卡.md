# 写后验收卡

## 阶段零：观察（先客观记录，不做判断）

> 设计来源：DeterminFlow 观察与裁决分离——先当"章节观察员"只列事实，再当"裁决器"做判断，防止带着立场检查。

### 观察清单（只列事实，不下结论）
- [ ] 本章事件清单（发生了什么，3-5条）
- [ ] 新出现的角色/地点/名词（登记或确认）
- [ ] 与上一章结尾的衔接点（有无首段承接）
- [ ] 本章出现的悬念点（列出来，不评价）
- [ ] 台词中的新信息（谁知道了什么）
- [ ] 疑似 AI 痕迹的段落（标记位置，不急着改）

## 验收一：字数
- 纯汉字 ≥ 2,000字（目标2,500 ± 500）
- 不足时原因：

## 验收二：推进检验
- 剧情比开头推进了
- 与写前三问的答案一致
- 推进量＜1个事件 → 标记「缓冲章」，下章加大推进

## 验收三：爽点检查
- 至少一个明确的事件级爽点
- 类型：技能突破/关系推进/收获反馈/冲突爆发/他人认可
- 不是内心感悟

## 验收四：节奏健康
- 没有连续3章以上平淡期
- 没有重复套路
- 没有过量环境描写（超过3句）

## 验收五：章末钩子
- 最后一段设了悬念/期待
- 钩子类型：未知信息/即将到来事件/情感铺垫/冲突预告
- 加钩子一句话能说清，不过于复杂

## 验收六：AI痕迹检测（自动调用 ai-trace-detector）
**扫描内容：** 8维度扫描（词汇模式/句式结构/情感温度/动作描写/对话自然度/逻辑连接/节奏韵律/个性化）

```
AI痕迹总分：__/10    人味评分：__/10
增强模式匹配：
- 同义词循环：[检出/未检出]
- 表面分析式着结构：[检出/未检出]
- 吹捧式语言：[检出/未检出]
- 三段式泛滥：[检出/未检出]
灵魂评分：[有灵魂/欠灵魂/无灵魂]
```

**判定：**
- 人味评分 ≥ 7分 → 通过
- 人味评分 ＜ 7分 → **退回文学精修仓**，精修后重新跑验收六
