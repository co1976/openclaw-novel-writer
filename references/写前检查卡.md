# 写前检查卡

## 三问（不可跳过）

### 问题一：推进
这章结束时剧情比开头推进了什么？删掉这章读者会不会觉得跳了什么？
- 不会 → 注水，重新设计
- 会 → 有存在必要

### 问题三：上章钩子接了吗？
上章最后一段的悬念/期待，本章是否直接回应？若不回应，说明原因：

### 问题四：伏笔/债务操作（对应台账）
- 埋 new：本章新设伏笔（至少1条，无预期回收区间不埋）
- 推 advance：哪条伏笔有进展
- 掀 resolve：本章回收哪条（掀1埋2）
- 债务：有到期的吗？谁还账？代价是什么？
- 台账核对：写不出区间的伏笔 = 废笔

### 附加：本章禁入

### 附加：本章信息黑洞（创作留白，不揭什么）
| 类型 | 位置 | 只写现象（写手指令） | 真实答案（作者备忘） | 最早揭示章 |
|------|------|---------------------|---------------------|-----------|
| motive_gap/detail_gap/rhythm_gap | 第X场 | 写手只写现象不写动机 | 作者脑中真实原因 | 0XX |

**纪律：** 每2000字≤3条，不能全同一类型。每条过岔路口测试（至少两种合理写法且结果不同）。写作时只写现象、不写动机——防解释腔、防提前剧透。

## 8要素章纲

```
【第X章 章名】

1. 本章一句话：
   [主角]在[场景]做[行动],导致[结果],引出[下章悬念]。

2. 必须出现的元素（写前锁定）：
   - [关键描写1]（为后续伏笔）
   - [关键对话2]（塑造人物/推进剧情）
   - [关键动作3]（情感/动作/权谋展现）

3. 情绪曲线（1-10分）：
   开场[分] → 发展[分] → 高潮[分] → 收尾[分]

4. 信息量目标：
   - 给读者：[具体信息]
   - 给角色：[具体信息]
   - 隐藏：[伏笔信息，对应台账操作：埋/推/掀]

5. 章末钩子：
   [一句话悬念]

6. 禁用/避让：
   - 不写[内容]（避免[风险]）
   - 不超过[字数]字
   - 不引入[新元素]

7. 快速自查（写前1分钟）：
   - 主角这章要什么？[可执行目标]
   - 谁在挡路？[具体人物/困境]
   - 本章结束时情况更糟还是更好？[必须变化]

8. 平台合规：
   - 字数：[2000-3000]
   - 分段：[每段≤5行]
   - 对话：[无连续3段纯对话]
```

## 场景节拍卡（6节点）

1. **开场承接**：上一章钩子如何落地
2. **第一压力点**：谁逼主角做选择
3. **中段反转**：信息/局面如何变坏或变爽
4. **爽点落地**：读者具体爽在哪一个动作/结果
5. **代价/余波**：爽完留下什么新问题
6. **章末钩子**：下一章必须想看的问题

硬性规则：第4条写不出不进正文；第6条写不出重设结尾。
